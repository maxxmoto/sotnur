# SOTNUR — Сайт бронирования домов

Полностью готовый к работе проект на Flask + JSON-базе данных.

## 🚀 Быстрый старт (локально)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python app.py
```

### 3. Открытие в браузере
- **Сайт:** http://127.0.0.1:5000
- **Админка:** http://127.0.0.1:5000/admin
- **Логин:** `admin`
- **Пароль:** `sotnur2026`

## 🔧 Управление данными

### Редактирование домов
1. Зайдите в админ-панель `/admin`
2. Нажмите «Добавить дом» или «Ред.» напротив нужного
3. Заполните: название, описание, цена, гости, удобства (через чекбоксы)
4. Сохраните

### Загрузка фотографий
- При редактировании дома можно добавить ссылки на изображения
- Формат: прямые ссылки (Unsplash, Yandex Disk, свой хостинг)
- Для локальной загрузки изображения сохраняйте в папку `uploads/`

### Управление календарём
1. В админке нажмите «Календарь» напротив дома
2. Клик по дате — переключение: свободно / занято
3. Занятые даты отображаются красным на сайте

### Бронирования
- Все заявки появляются в таблице «Бронирования»
- Меняйте статус: Новое → Подтверждено → Отменено

### Отзывы
- Добавляйте отзывы с привязкой к конкретному дому
- Указывайте автора, оценку (звезды), текст

## 🌐 Деплой на Amvera

### Шаг 1: Подготовка репозитория
1. Зарегистрируйтесь на [Amvera](https://amvera.ru)
2. Создайте новый проект
3. Подключите Git-репозиторий (или загрузите архив)

### Шаг 2: Настройка
В корне проекта создайте файл `app.yaml`:
```yaml
name: sotnur
runtime: python310
build:
  packages:
    - flask
    - werkzeug
  command: python app.py
```

### Шаг 3: Деплой
1. Нажмите «Деплой» в панели Amvera
2. Дождитесь сборки и запуска
3. Получите URL вида: `https://your-app.amvera.ru`

### Шаг 4: Привязка домена
1. Купите домен (например, на REG.RU или Namecheap)
2. В панели Amvera перейдите в «Настройки» → «Домены»
3. Добавьте ваш домен
4. В настройках DNS домена добавьте записи:
   - CNAME: `your-app.amvera.ru`
   - или A-запись с IP-адресом сервера Amvera

### Пример настройки DNS (REG.RU):
| Тип | Имя | Значение |
|-----|-----|----------|
| CNAME | www | your-app.amvera.ru |
| A | @ | (IP Amvera) |

## 🎨 Кастомизация

### Цвета
Измените в `static/style.css`:
```css
:root {
    --primary: #667eea;    /* Основной цвет */
    --secondary: #764ba2; /* Дополнительный */
    --accent: #e94560;     /* Акцентный */
}
```

### Тексты
- Редактируйте directly в HTML-шаблонах
- Контакты: `templates/base.html` (секция contacts)
- Описание домов: `data.json`

## ⚠️ Важно

1. **Сессии** — в `app.py` используется SECRET_KEY. Для продакшена смените на сложную строку.
2. **Безопасность** — не храните критичные данные в JSON. Для большого проекта перейдите на PostgreSQL.
3. **Изображения** — текущая версия работает с URL-ссылками. Для загрузки с диска настройте Nginx.
4. **Календарь** — даты хранятся в `data.json`. При большой нагрузке перенесите в БД.
